# vue-person-example

Simple Vue 3 + Vite + TypeScript example with authentication and protected routes.

## Prerequisites

- Node.js > 24

## Run & Debug

- `.env` for local development
- `.env.local` for local development overrides if needed

- `npm i`

- run app: `npm run dev`
- debug app: `npm run dev` + `Debug Vue App - ...` in Debug View in VSCode

## Chore

### Update dependencies

```bash
npm outdated
npm update
npm audit fix

# to update major version
npx npm-check-updates
npx npm-check-updates -u
npm install

# or using npm-check
npm-check -u
```
